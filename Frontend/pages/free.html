Three useful first steps

Short introductions to concepts you'll meet as you learn to build for the web.

01

Give a page structure

HTML describes the content on a page. Start with a document, add a heading with <h1>, then group related text in elements such as <p> and <section>.

Explore HTML →
02

Make it readable

CSS controls presentation. Use spacing to separate ideas, keep text contrast comfortable, and let flexible layouts adapt to different screen sizes.

Explore CSS →
03

Add a little logic

JavaScript can respond to user actions. A good first exercise is to select a button, listen for a click, and update a message on the page.
